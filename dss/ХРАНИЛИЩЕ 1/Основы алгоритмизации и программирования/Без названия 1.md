**Что такое язык программирования?**  
**Б) Формальный язык для записи алгоритмов, понятный компьютеру**  
_Пояснение:_ Язык программирования — это строгий набор правил и символов, которые компьютер (или интерпретатор/компилятор) может преобразовать в машинные команды.  
А) Естественный язык для общения между программистами  
В) Графический интерфейс для создания программ  
Г) Программа для перевода текста с одного языка на другой

---

**Чем язык программирования отличается от естественного языка?**  
**Б) Он абсолютно однозначен и не допускает двусмысленности**  
_Пояснение:_ В программировании каждая конструкция должна трактоваться однозначно — иначе код не сработает. В естественном языке одно слово может иметь несколько значений.  
А) Он более красивый и выразительный  
В) На нём нельзя писать письма  
Г) Он меняется каждый год

---

**Какое из перечисленных утверждений верно для языков четвертого поколения?**  
**Б) Они являются непроцедурными и описывают, что надо получить, а не как**  
_Пояснение:_ Языки 4GL (например, SQL) декларативны: ты говоришь «дай мне данные», а не пишешь пошагово, как их выбрать.  
А) Они используют мнемонические обозначения вместо двоичного кода  
В) Они программируются напрямую двоичными числами  
Г) Они появились в 1940-х годах

---

**Какой язык относится к языкам высокого уровня?**  
**В) Python**  
_Пояснение:_ Языки высокого уровня (Python, Java, C#) абстрагированы от «железа», читаемы и удобны для человека. Ассемблер и машинный код — это низкий уровень.  
А) Assembler  
Б) Машинный код  
Г) Двоичный код

---

**Какая парадигма программирования предполагает описание программы как набора взаимодействующих объектов с данными и методами?**  
**Г) Объектно-ориентированная**  
_Пояснение:_ В ООП программа строится из объектов, которые объединяют состояние (данные) и поведение (методы).  
А) Процедурная  
Б) Логическая  
В) Функциональная

---

**Какой язык был создан для работы с реляционными базами данных и не является языком общего назначения?**  
**Б) SQL**  
_Пояснение:_ SQL (Structured Query Language) создан специально для запросов к базам данных, а не для написания игр, сайтов или системного ПО.  
А) Python  
В) Java  
Г) C++

---

**Для какой сферы преимущественно используется язык SQL?**  
**В) Работа с реляционными базами данных**  
_Пояснение:_ SQL — стандарт для CRUD-операций (Create, Read, Update, Delete) в БД вроде PostgreSQL, MySQL, SQL Server.  
А) Разработка игр  
Б) Создание веб-интерфейсов  
Г) Написание драйверов устройств

---

**Чем отличаются языки низкого уровня от языков высокого уровня?**  
**В) Языки низкого уровня близки к аппаратному обеспечению и быстрее выполняются**  
_Пояснение:_ Машинный код и ассемблер работают напрямую с процессором, поэтому быстрее, но сложнее в написании и отладке.  
А) Языки низкого уровня быстрее разрабатывать  
Б) Языки низкого уровня лучше переносимы  
Г) Языки низкого уровня легче изучать

---

**Что такое декларативный язык программирования?**  
**Б) Язык, который описывает желаемый результат, а не способ его получения**  
_Пояснение:_ Пример — SQL: `SELECT * FROM users WHERE age > 18` — ты говоришь «что», а не «как» обойти таблицу.  
А) Язык, который описывает пошаговый алгоритм действий  
В) Язык, который выполняется только на сервере  
Г) Язык, который компилируется в машинный код

---

**Что такое синтаксис языка программирования?**  
**Б) Правила записи конструкций языка**  
_Пояснение:_ Синтаксис — это «грамматика» языка: где ставить скобки, точки с запятой, как объявлять переменные и т.д.  
А) Смысловое значение конструкций  
В) Документация по стандартной библиотеке  
Г) Скорость выполнения программы

---

**Что такое IDE?**  
**Б) Интегрированная среда разработки, объединяющая инструменты для написания кода**  
_Пояснение:_ IDE (например, VS Code, Visual Studio, PyCharm) включает редактор кода, отладчик, компилятор/интерпретатор и другие инструменты в одном окне.  
А) Программа для перевода кода в машинный язык  
В) Язык программирования для веб-разработки  
Г) Операционная система для программистов

---

**Какие три основных компонента входят в состав любой IDE?**  
**А) Редактор, компилятор/интерпретатор, отладчик**  
_Пояснение:_ Это ядро IDE: пишешь код → компилируешь/запускаешь → ищешь ошибки.  
Б) Браузер, текстовый процессор, калькулятор  
В) Компилятор, антивирус, файловый менеджер  
Г) Отладчик, графический редактор, почтовый клиент

**В чем принципиальная разница между компилятором и интерпретатором?**  
**Б) Компилятор переводит весь код сразу в исполняемый файл, а интерпретатор выполняет код построчно**  
_Пояснение:_ C++ → компилятор → .exe файл. Python → интерпретатор → выполняет строку за строкой при запуске.  
А) Компилятор работает быстрее интерпретатора  
В) Интерпретатор создает исполняемый файл, а компилятор — нет  
Г) Компилятор используется только для Python

А) Только цвет переменной в редакторе  
В) Только имя переменной  
Г) Скорость выполнения программы

А) int  
Б) char  
Г) float

**Что такое массив?**  
**Б) Упорядоченный набор элементов одного типа, доступных по индексу**  
_Пояснение:_ Массив — это как коробка с ячейками: `arr[0]`, `arr[1]`... Все элементы одного типа (в статических массивах).  
А) Переменная, хранящая одно целое число  
В) Функция, выполняющая арифметические действия  
Г) Именованная константа

**Чем класс отличается от структуры?**  
**Б) Класс объединяет данные и методы, а структура — только данные (в базовом понимании)**  
_Пояснение:_ В C++ и C# структуры могут иметь методы, но исторически и концептуально классы — основа ООП с наследованием, полиморфизмом и т.д.  
А) Структура содержит только методы, а класс — только данные  
В) Структура обязательно наследуется, а класс — нет  
Г) Класс занимает меньше памяти, чем структура

**Для чего используется перечисляемый тип (enum)?**  
**Б) Для описания набора именованных констант, чтобы ограничить допустимые значения**  
_Пояснение:_ Пример: `enum Color { Red, Green, Blue }` — переменная типа `Color` может быть только одним из этих трёх значений.  
А) Для создания массивов  
В) Для работы с дробными числами  
Г) Для перевода строк в верхний регистр
