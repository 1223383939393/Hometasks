Множество — это структурированный тип данных, который хранит уникальные элементы без определённого порядка (по умолчанию). В Java множества представлены интерфейсом Set и его реализациями. 

`Set langs = new HashSet<>();` 
`langs.add("Java");`
`System.out.println(langs);`

Перебор элементов реализуется через for-each:

`for (String lang : langs) {` 
`System.out.println(lang);` 
`}`
