# Быстрый старт: Как работает SmartDelivery

Прежде чем переходить к интеграции, важно понимать бизнес-логику нашего сервиса.

## Жизненный цикл заказа

1. Создание заказа
   Клиент формирует корзину в мобильном приложении. Система проверяет наличие товаров на складе.
2. Резервирование
   Если товары есть, они резервируются на 15 минут. Создается сущность Order со статусом PENDING.
3. Оплата
   Клиент оплачивает заказ. Система получает вебхук от платежного шлюза и меняет статус на PAID.
4. Передача в доставку
   Заказ автоматически передается ближайшему курьеру через систему геолокации.

## Статусы заказа

| Статус | Описание | Доступные действия |
| :--- | :--- | :--- |
| NEW | Заказ создан, ждет оплаты | Отмена, Оплата |
| PAID | Оплата прошла успешно | Сборка на складе |
| DELIVERING | Передан курьеру | Отслеживание |
| DONE | Успешно доставлен | Оценка, Повтор |

> ⚠️ Важно: Статус DELIVERING не может быть отменен клиентом в одностороннем порядке.
