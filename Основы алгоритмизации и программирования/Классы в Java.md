## Что такое класс

Класс — это шаблон (чертёж) для создания объектов. Он описывает, какие данные (поля) будут у объекта и какие действия (методы) он умеет выполнять.

Представь: класс — это чертёж дома, а объект — сам дом. По одному чертежу можно построить сколько угодно домов, и у каждого будут свои особенности (цвет стен, жильцы), но структура одинаковая.

**Класс = поля (данные) + методы (поведение)**

### Пример

```java
public class Student {
    // Поля (данные)
    String name;
    int age;
    double grade;

    // Методы (поведение)
    void study() {
        System.out.println(name + " учится");
    }
}
```

Здесь `Student` — это класс. Он описывает, что у любого студента есть имя, возраст, оценка и что студент умеет учиться.

## Зачем нужны классы

Без классов программа — это набор разрозненных переменных и функций.

### Пример без класса

```java
// Без класса — данные «размазаны» по коду
String student1Name = "Аня";
int student1Age = 20;
double student1Grade = 4.5;

String student2Name = "Иван";
int student2Age = 22;
double student2Grade = 3.8;
```

### Проблемы

1. Данные одного студента не связаны — легко перепутать.
2. Чтобы передать студента в функцию — нужно передавать 3 параметра.
3. Нет способа сказать «этот набор данных — единое целое».

### Тот же пример с классом

```java
Student s1 = new Student("Аня", 20, 4.5);
Student s2 = new Student("Иван", 22, 3.8);
```

### Преимущества

1. Данные объединены — один объект = один студент.
2. Переиспользование — один класс → много объектов.
3. Читаемость — `s1.getName()` понятнее, чем `student1Name`.
4. Инкапсуляция — можно скрыть внутреннее устройство.
5. Код становится читабельнее.

## Отличие класса от метода


|                     | Класс                                                                                                                                  | Метод                                                                                                      |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Что это             | шаблон (чертёж) для создания объектов. Он описывает, какие данные (поля) будут у объекта и какие действия (методы) он умеет выполнять. | именованный блок кода, который выполняет определённую задачу и может быть вызван из других мест программы. |
| Что содержит в себе | Поля и методы                                                                                                                          | Инструкции(команды), которые выполняется                                                                   |
| Как лучше называть  | Существительным с большой буквы                                                                                                        | Глаголом с маленькой буквы, по сути действием которое оно делает                                           |
| Синтаксис           | class Student { ... }                                                                                                                  | void study() { ... }                                                                                       |
| Где живет           | В отдельном файле класса                                                                                                               | Внутри класса или просто внутри файла                                                                      |
| Пример              | public class Student { String name; void study() { ... } }                                                                             | void study() { System.out.println("Учусь"); }                                                              |


- **Класс** — шаблон для создания объектов, содержит поля и методы.
- **Метод** — действие или поведение, которое может выполнять объект.

```java
class Student { ... }   // класс
void study() { ... }    // метод
```

## Основные элементы класса

### 1. Поля

Поля — данные объекта.

```java
class Person {
    String name;             // поле
    int age;                 // поле
    private double salary;   // поле с модификатором доступа
}
```

### 2. Методы

Методы — поведение объекта.

```java
class Person {
    void greet() {
        System.out.println("Привет, я " + name);
    }
}
```

### 3. Конструктор

Конструктор — специальный метод для создания объекта.

```java
class Person {
    String name;
    int age;

    // Конструктор
    Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

Особенности конструктора:

- Называется так же, как класс.
- Не имеет возвращаемого типа (даже `void`).
- Вызывается при создании объекта через `new`.
- Если его не написать, Java автоматически создаст пустой конструктор по умолчанию.

## Модификаторы доступа

Модификаторы доступа определяют, откуда можно обращаться к полям, методам и классам.

- `public` — доступен отовсюду.
- `private` — доступен только внутри своего класса.
- `protected` — доступен внутри пакета и в классах-наследниках.
- Без модификатора (package-private) — доступен только внутри своего пакета.

Чаще всего поля делают `private`, а доступ к ним дают через геттеры и сеттеры. Это защищает данные от неконтролируемого изменения.

```java
class Person {
    private String name;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}
```

## static и static final

### static

`static` означает, что элемент принадлежит не объекту, а самому классу.

- Статическое поле одно для всех объектов класса.
- Статический метод можно вызвать без создания объекта.

```java
class MathUtils {
    static int counter = 0;

    static int square(int number) {
        return number * number;
    }
}
```

```java
int result = MathUtils.square(5); // 25
```

`static` применяют для общих данных, счётчиков, утилитных методов и констант.

### static final

`static final` — это константа: она принадлежит классу и её нельзя изменить после создания.

```java
class Config {
    static final int MAX_USERS = 100;
}
```

Имена констант принято писать заглавными буквами: `MAX_USERS`.

## this

`this` — ссылка на текущий объект.

Его используют, чтобы отличить поле класса от параметра метода или конструктора с таким же именем.

```java
class Person {
    private String name;

    public Person(String name) {
        this.name = name; // this.name — поле, name — параметр
    }
}
```

Также `this` применяют для вызова другого конструктора этого же класса:

```java
class Person {
    private String name;
    private int age;

    public Person() {
        this("Неизвестно", 0);
    }

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

## Инкапсуляция, геттеры и сеттеры

Инкапсуляция — это скрытие внутренних данных класса и предоставление доступа к ним только через специальные методы.

Зачем это нужно:

- Защищает данные от неправильного изменения.
- Позволяет контролировать доступ к полям.
- Упрощает изменение внутренней реализации без изменения кода других классов.

### Геттер

Геттер — метод для получения значения поля.

```java
public String getName() {
    return name;
}
```

### Сеттер

Сеттер — метод для изменения значения поля.

```java
public void setName(String name) {
    this.name = name;
}
```

### Отличие

- **Геттер** возвращает значение поля.
- **Сеттер** устанавливает новое значение поля.
- В геттере обычно есть `return`, а в сеттере — параметр и `this`.

## Методы toString(), equals(), hashCode()

### toString()

`toString()` возвращает строковое представление объекта.

Он нужен для удобного вывода объекта на экран.

```java
@Override
public String toString() {
    return "Person{name='" + name + "', age=" + age + "}";
}
```

Без переопределения `toString()` Java выведет что-то вроде `Person@1b6d3586`, что неинформативно.

### equals()

`equals()` сравнивает два объекта по содержанию, а не по ссылке.

```java
@Override
public boolean equals(Object obj) {
    if (this == obj) return true;
    if (obj == null || getClass() != obj.getClass()) return false;

    Person person = (Person) obj;
    return age == person.age && name.equals(person.name);
}
```

По умолчанию `equals()` сравнивает ссылки: два разных объекта с одинаковыми данными будут считаться разными. Переопределение позволяет сравнивать их по значениям полей.

### hashCode()

`hashCode()` возвращает числовой код объекта.

Он используется в коллекциях `HashMap`, `HashSet` и `Hashtable` для быстрого поиска объектов.

Правило: если два объекта равны через `equals()`, то их `hashCode()` должен быть одинаковым.

```java
@Override
public int hashCode() {
    return Objects.hash(name, age);
}
```

## Шаблон класса

```java
public class ИмяКласса {
    // 1. Поля
    private тип поле1;
    private тип поле2;

    // 2. Конструктор
    public ИмяКласса(тип поле1, тип поле2) {
        this.поле1 = поле1;
        this.поле2 = поле2;
    }

    // 3. Геттеры
    public тип getПоле1() {
        return поле1;
    }

    // 4. Сеттеры
    public void setПоле1(тип поле1) {
        this.поле1 = поле1;
    }

    // 5. Методы
    public тип метод() {
        // ...
    }

    // 6. toString
    @Override
    public String toString() {
        return "...";
    }
}
```
