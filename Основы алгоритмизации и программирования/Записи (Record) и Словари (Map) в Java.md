 Запись (record) — это специальный тип класса, предназначенный для хранения неизменяемых данных.
 
  public record Person(String name, int age) { } 
  public class Main { 
  public static void main(String[] args) { 
		  Person p = new Person("Аня", 25); 
		  System.out.println(p.name()); // Аня 
		  System.out.println(p.age()); // 25 
		  System.out.println(p); // Person[name=Аня, age=25] 
     }
   }

   Сравнительная таблица: Record vs Map

| Тип                | Record                                                                                                                                                                                                             | Map                                                                                                                                                                                                                |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Что это            | специальный тип данных, появившийся в **Java 16**, который позволяет создавать **неизменяемые классы-держатели данных** с минимальным количеством кода. Это как POJO (Plain Old Java Object), но короче и удобнее. | интерфейс для хранения данных в виде **ключ-значение** (`key-value`). Каждый ключ уникален, значения могут повторяться. Это не коллекция в полном смысле (не реализует `Collection`), но очень полезная структура. |
| Набор полей        | Фиксированный — задаётся один раз при объявлении record, изменить нельзя                                                                                                                                           | Динамический — можно добавлять, удалять, изменять пары в любое время                                                                                                                                               |
| Изменяемость       | Полностью неизменяемый (immutable) — все поля `private final`, нет сеттеров                                                                                                                                        | Изменяемый (mutable) — можно менять содержимое через `put()`, `remove()` и т.д.                                                                                                                                    |
| Скорость           | Как обычный класс — доступ к полям за O(1), методы генерируются компилятором                                                                                                                                       | `HashMap`/`LinkedHashMap`: O(1) на `put`/`get`  <br>`TreeMap`: O(log n) из-за сортировки                                                                                                                           |
| Память             | Компактный — минимум кода, нет лишних геттеров/сеттеров, `equals`/`hashCode`/`toString` автоматические                                                                                                             | Требует больше памяти — хранит внутреннюю структуру (хэш-таблицу или дерево), Entry-объекты                                                                                                                        |
| Когда использовать | ✅ Модель данных (DTO, ответ от API, запись из БД)  <br>✅ Кортеж из нескольких значений  <br>✅ Ключ для `HashMap` (потому что `equals`/`hashCode` уже есть)  <br>✅ Когда данные не должны меняться                  | ✅ Словарь (например, слово → перевод)  <br>✅ Подсчёт частоты элементов  <br>✅ Кэш (ключ → значение)  <br>✅ Когда нужно быстро искать по ключу  <br>✅ Группировка данных                                            |
| Пример             | java<br>record Person(String name, int age) {}<br><br>Person p = new Person("Alice", 25);<br>System.out.println(p.name()); // "Alice"<br>                                                                          | java<br>Map<String, Integer> ages = new HashMap<>();<br>ages.put("Alice", 25);<br>ages.put("Bob", 30);<br><br>System.out.println(ages.get("Alice")); // 25<br>                                                     |
