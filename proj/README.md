## 1. Краткое описание задачи

Было необходимо разработать микросервис для расчёта стоимости бронирования билетов для стартапа «КиноРФ».  
Язык реализации: **Python**.

Функция расчёта:

```python
calculate_total(base_price, age, is_weekend, promo_code) -> int
```

### Бизнес-правила расчёта

1. **Базовая цена** (`base_price`): целое число, строго больше 0.
2. **Скидка по возрасту**: если `age < 18` или `age >= 65`, применяется скидка **20%** от базовой цены.
3. **Промокод** `STUDENT2026`: дополнительная скидка **15%** от цены после возрастной скидки.  
   - **Важно:** промокод **не суммируется** с возрастной скидкой. Если у пользователя есть право на возрастную скидку, промокод игнорируется — применяется только скидка 20%.
4. **Наценка за выходные**: если `is_weekend == True`, к итоговой цене (после всех скидок) добавляется **100 рублей**.
5. **Минимальная стоимость**: итоговая цена не может быть меньше **50 рублей**.

## 5. Работа с баг-трекером (обязательный этап)

### Шаг А. Намеренное внесение ошибки

В функцию `calculate_total` в `src/pricing.py` была намеренно удалена (или закомментирована) строка:

```python
price = max(price, 50)
```

Это нарушило бизнес-правило **«минимальная стоимость — 50 рублей»**.

### Шаг Б. Тест, который падает из-за ошибки

Тест: `tests/test_pricing_unit.py::TestBugDemonstration::test_minimum_price_enforced`  
А также: `tests/test_pricing_unit.py::TestMinimumPrice::test_price_below_minimum_rounds_to_50`

**Ожидаемое поведение:**  
При `calculate_total(40, 17, False, None)` цена должна быть **50 рублей**.

**Фактическое поведение (до исправления):**  
Цена была **32 рубля** (40 * 0.8 = 32, без ограничения снизу).

Результат:

```text
FAILED tests/test_pricing_unit.py::TestBugDemonstration::test_minimum_price_enforced
AssertionError: Минимальная цена должна быть 50 рублей
assert 32 == 50
```

### Шаг В. Баг-репорт

**Заголовок:**  
Итоговая цена становится ниже 50 рублей при большой скидке

**Окружение:**

- ОС: Windows 11
- Python: 3.14.3
- pytest: 9.0.3
- pytest-cov: 7.1.0

**Описание проблемы:**  
При применении возрастной скидки 20% к маленькой базовой цене итоговая стоимость может быть меньше 50 рублей, что нарушает бизнес-правило «минимальная стоимость — 50 рублей».

**Шаги для воспроизведения:**

1. Вызвать `calculate_total(40, 17, False, None)`
2. Ожидается: 50
3. Фактически: 32

**Локализация ошибки:**  
Файл: `src/pricing.py`, функция `calculate_total`, отсутствует строка `price = max(price, 50)`.

**Приоритет:** High — нарушает бизнес-правило.

### Шаг Г. Исправление и проверка

**Исправление:**  
В `src/pricing.py` перед `return` добавлена строка:

```python
price = max(price, 50)
```

**Проверка:**  
Повторный запуск:

```bash
py -m pytest -v
```

Все 36 тестов стали **PASSED**, включая тесты на минимальную стоимость. Баг закрыт.
