# Этапы проектирования баз данных
## 1. Концептуальное проектирование
Cбор, анализ, редактирование требований к данным, построение концепт моделей предметной области

## 2. Логическое проектирование
Преобразование инфологической модели структуры данных, выбранной СУБД

## 3. Физическое проектирование
Определение особенностей хранения данных, методов доступа и тд.

# Определение требований к системе

1. Цели создания системы
2. Объема и типов данных
3. Способы использования данных
4. Бизнес правила и ограничения
# Назначение системы

1. Изучить реальные процессы предметной области
2. Выделить основную цель создания системы
3. Определить способы измерения целей

# Объем и типы данных

1. Опросить специалистов предметной области и изучить документы
2. Выделить категории данных, которые предполагается хранить в базе, а также выяснить, какие именно сведения о каждой категории будут храниться
3. Определить реальный объем данных и тенденцию роста

# Способы использования данных

1. Кто будет обращаться к данным
2. Разделить пользователей на категории
3. Сколько пользователей будут одновременно использовать БД
4. Определить задачи которые будут решать пользователи

# Бизнес правила системы

1. Определить ограничения целостности данных(условия, связи, пустые значения)
2. Определить бизнес правила(общие действия, выполняемое ПО над данными)
