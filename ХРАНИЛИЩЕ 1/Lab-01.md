## Задача «Библиотечный каталог»

**Цель:** закрепить наследование, абстрактные классы, переопределение методов и полиморфизм в C#.

### Требования

1. Создать **абстрактный класс** `Publication`:
   - свойства:
     - `string Title` — название;
     - `string Author` — автор;
     - `int Year` — год издания;
     - `string InventoryNumber` — инвентарный номер.
   - конструктор для инициализации этих свойств;
   - абстрактный метод:
     ```csharp
     public abstract string GetInfo();
     ```

2. Создать три класса-наследника:
   - `Book` — дополнительные свойства: `string Genre`, `int Pages`;
   - `Magazine` — дополнительные свойства: `int IssueNumber`, `string Month`;
   - `Newspaper` — дополнительное свойство: `DateTime IssueDate`.

   Каждый наследник обязан переопределить `GetInfo()` и вернуть строку с общей и своей специфической информацией.

3. Создать класс `Library`:
   - приватное поле:
     ```csharp
     private List<Publication> _publications = new();
     ```
   - метод `void Add(Publication publication)` — добавляет публикацию в список;
   - метод `void PrintCatalog()` — перебирает `_publications` и вызывает `GetInfo()` у каждого элемента;
   - метод `List<Publication> FindByAuthor(string author)` — возвращает все публикации указанного автора.

4. В `Main`:
   - создать не менее 5 объектов разных типов (`Book`, `Magazine`, `Newspaper`);
   - добавить их в `Library`;
   - вывести каталог на экран;
   - найти публикации по автору и вывести результат.

### Главное условие полиморфизма

В методах `PrintCatalog()` и `FindByAuthor()` **нельзя** использовать проверки конкретного типа:
```csharp
if (item is Book)
switch (item)
```
и нельзя делать приведение к `Book`, `Magazine`, `Newspaper`.  
Методы должны работать только с типом `Publication`, а нужное поведение вызывается через переопределённый `GetInfo()`.

### Дополнительно, по желанию

- Добавить интерфейс `ILateFee`:
  ```csharp
  public interface ILateFee
  {

  }
  ```
  Реализовать его по-разному:
  - книга — 5 руб./день;
  - журнал — 3 руб./день;
  - газета — 1 руб./день.

  ```csharp

  ```
  который считает общую сумму задолженности по всем публикациям.

- Добавить сортировку каталога по году издания.
- Добавить поиск по инвентарному номеру.
